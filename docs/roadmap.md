# Roadmap

Commons should launch in **one country first**, because identity schemes and parliamentary customs differ by jurisdiction.

## Phase 0: Foundations
- Choose the launch country and identity provider
- Choose the tech stack and architecture
- Write the code of conduct
- Design the data model (users, roles, posts, debates, polls)

## Phase 1: MVP
- Verified sign-up (via an identity provider, with a stub for development)
- Per-session re-verification with passkeys
- Profiles with verified roles
- Feed: posts, replies, follows, citations
- Formal debates: motion, For/Against sides, rounds, before-and-after vote
- Simple polls
- Basic moderation: reporting, and the chair role in debates

## Phase 2: Engagement with officials
- Official accounts tied to offices
- Constituency verification and local chambers
- Question Time
- Petitions with response thresholds

## Phase 3: Deliberation tools
- Argument maps
- Deliberative polling and consensus finding
- AI neutral briefings and the "pause before posting" check
- Standing score

## Phase 4: Policy pipeline
- Collaborative policy drafting with amendments
- Committee-style hearings
- Export to consultations
- Statements vs. voting record
